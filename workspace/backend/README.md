# Caeru API (work in progress)

O plano de controle usa um banco dedicado, distinto dos bancos GBrain. Para executar localmente, copie `.env.example` para `.env` neste diretório e defina uma senha local em `POSTGRES_PASSWORD` e na `DATABASE_URL`, além de um `BETTER_AUTH_SECRET` aleatório. Execute `docker compose up -d --wait`, `bun install`, `bun run db:generate`, `bun run db:migrate` e `bun run dev`. Em outro terminal, na pasta `workspace`, execute `bun install` e `bun run dev`; acesse `http://127.0.0.1:5173`. O Vite encaminha `/api` à API local. Para usar Google, registre `http://127.0.0.1:5173/api/auth/callback/google` no OAuth e preencha as credenciais no `.env` do backend.

Este trabalho ainda não é uma entrega completa: não há provisionador nem adaptador GBrain; instâncias permanecem `PENDING`, e somente Brains com instância pendente podem ser excluídos; outros estados exigirão limpeza coordenada. Convites são registrados pelo Better Auth e compartilhados por link manual; para aceitá-los, o e-mail precisa estar verificado. Ainda não há envio de e-mail de verificação nem de recuperação de senha; contas Google com e-mail verificado podem aceitar convites. O frontend apresenta estados indisponíveis nas áreas não integradas e não exibe dados demonstrativos após o login. Não use para produção.

Os testes de integração usam `DATABASE_URL` e criam e apagam somente suas próprias fixtures; execute-os exclusivamente contra um banco de testes dedicado já migrado. O teste cobre autorização do controller contra PostgreSQL, não um fluxo completo de login OAuth.
